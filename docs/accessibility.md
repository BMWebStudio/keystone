# Accessibility principles

- Prefer native HTML constraints before ARIA.
- Preserve existing `aria-describedby` references.
- Communicate errors with inline text next to each field, never color alone.
- Focus the first invalid field after a blocked submission.
- Remove only validator-owned state after correction.
- Treat automated scans as guidance, not certification.
- Test keyboard, zoom, reduced motion, and screen-reader behavior.
